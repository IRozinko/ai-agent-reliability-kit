# AI Agent Reliability Kit

A lightweight framework for testing AI agents, LLM workflows, prompt regression, tool-use risks, output evaluation, audit trails and production readiness.

## Goals

- Detect regressions in prompts and outputs
- Validate allowed and forbidden tool use
- Track risky behavior and hallucination patterns
- Preserve audit trails for AI decisions
- Build release gates for AI-enabled features

## Core checks

- Prompt regression
- Output expectation tests
- Forbidden-output tests
- Tool-permission tests
- Data-leakage checks
- Human escalation checks
